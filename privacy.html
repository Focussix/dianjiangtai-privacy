Privacy Policy

For the browser extension Dianjiangtai (store name: Muster · PoE Trade Helper)
Effective date: November 10, 2026

In one line: this extension does not collect, upload, or sell any of your personal information.

No account system, no analytics, no ads, no third-party tracking scripts. All settings stay in your own browser.

1. What the extension does

Dianjiangtai is a helper tool that runs on the official Path of Exile trade site. It translates the stat filter panel into Chinese, shows stat tiers (T1, T2, ...), flattens the nested item type picker into one level, and provides a unique item list. It works only inside the trade page.

2. What page content the extension reads

To work, the extension must read content that is already publicly visible on the trade page, including:

  • option names and ids of the stat filter panel (to display Chinese names and tier labels);
  • the current control structure of the search filter area (to relocate controls into the panel);
  • item names and property text in search results (for name recognition highlighting).

This content is processed only in your browser's memory. It is never sent to any server and never written to remote storage.

3. What the extension stores

The extension stores your preferences locally, for example: feature toggle states, UI language mode, collapsed section states, whether to show the English original text, and the time of the last update check.

  • Stored in the local storage (localStorage) that the browser provides for the trade site. Keys are prefixed with dj.. Not uploaded, not encrypted-in-transit, not synced across devices.
  • Contains no personally identifiable information.
  • Removed when you uninstall the extension or clear its data. We can neither access nor recover it.

4. Permissions and their purpose

  • This extension does not request the storage permission. Preferences live in the trade site's own localStorage (keys prefixed with dj.), containing only toggles and modes, no personal information.
  • https://poe.game.qq.com/* and https://*.pathofexile.com/* — the panel is injected only on the official Chinese and international trade sites. The extension does not run on any other website.
  • https://dianjiangtai-update.app.workbuddy.host/* — used only to read a plain-text version number file (version.txt) so the panel can show a "new version available" hint. No data is sent; it is a single GET request.

5. Network requests

Apart from loading dictionary and image files bundled inside the package, the extension makes exactly one request, on "check for update", to fetch a version number text such as 1.2.3.

That request is served by the extension's own server, which may keep regular access logs (IP address, browser User-Agent, timestamp). These logs are used only for troubleshooting and visit counting, are not linked to any account or personal identity, and are not used for advertising or profiling.

The extension does not download or execute any remote code. All logic is bundled in the installation package.

6. Sharing with third parties

None. We do not sell, rent, or otherwise provide your data to third parties, because no data is collected in the first place.

Limited Use compliance. This extension follows the Chrome Web Store Limited Use requirements:

  • User data is not sold or transferred to third parties outside of approved use cases;
  • User data is not used or transferred for purposes unrelated to the extension's single purpose;
  • User data is not used or transferred to determine creditworthiness or for lending purposes.

The extension collects no user data at all, so none of these cases can occur.

7. Your choices

  • Turn off any feature toggle in the panel at any time; the corresponding logic stops running.
  • Disable or uninstall the extension from your browser's extension manager at any time.
  • Clear the extension's data to delete all local settings.

8. Children's privacy

This extension is intended for Path of Exile players. It is not designed for children and does not knowingly collect information from children.

9. Changes to this policy

If a future change to the extension alters how data is handled, this page will be updated and the effective date above revised. Significant changes will also be noted in the extension's release notes.

10. Contact

Questions about this policy can be raised in the Reviews section of the extension's store listing page, or in the Chinese community thread on the Caimogu forum: caimogu.cc/post/2517714.html

点将台 · 隐私政策

适用于浏览器扩展「点将台 · PoE 交易市集助手」　生效日期：2026 年 11 月 10 日

一句话结论：本扩展不收集、不上传、不出售你的任何个人信息。

没有账号体系，没有统计埋点，没有广告，没有第三方追踪脚本。所有设置只存在你自己的浏览器里。

一、扩展是做什么的

点将台是一个在《流放之路》官方交易市集页面上运行的辅助工具，帮玩家把词缀面板转成中文、显示词缀等级（T 级）、平铺物品类型、列出传奇清单等。它只在市集页面内工作。

二、扩展会读取哪些页面内容

扩展需要读取市集页面上已公开显示的内容才能工作，包括：

  • 词缀筛选面板里的选项名称与编号（用于显示中文和 T 级）；
  • 搜索条件区域当前的控件结构（用于把控件挪到面板里）；
  • 物品搜索结果里的物品名称与属性文本（用于名称识别高亮）。

这些内容只在你的浏览器内存中处理，不发送到任何服务器，也不写入任何远程存储。

三、扩展保存了什么

扩展在本机保存你的偏好设置，例如：功能开关状态、界面语言档位、面板折叠状态、是否显示英文对照、上次检查更新的时间。

  • 这些数据存放在浏览器为市集站点提供的本地存储（localStorage）里，键名统一以 dj. 开头，不加密上传、不跨设备同步；
  • 不包含任何可识别个人身份的信息；
  • 卸载扩展或清除扩展数据后即被删除。我们无法访问、也无法恢复。

四、各项权限的用途

  • 本扩展不申请 storage 权限。偏好设置直接存在市集站点自己的 localStorage 里（键名以 dj. 开头），内容只有开关与档位，不含任何个人信息。
  • https://poe.game.qq.com/*、https://*.pathofexile.com/* —— 扩展只在国服与国际服的交易市集页面注入面板，不在其他网站运行。
  • https://dianjiangtai-update.app.workbuddy.host/* —— 仅用于读取一个纯文本版本号文件（version.txt），以便在面板角落提示「有新版本」。不发送任何数据，只做一次 GET 请求。

五、网络请求说明

除加载扩展自身打包在内部的词典与图片文件外，本扩展只在「检查更新」时发起一次请求，取回形如 1.2.3 的版本号文本。

该请求由扩展的服务器承担，服务器可能按常规记录访问日志（IP 地址、浏览器 User-Agent、时间）。这些日志仅用于排查故障与统计访问量，不与任何账号或个人身份关联，也不用于广告或用户画像。

扩展不会下载或执行任何远程代码；所有逻辑都打包在安装包内。

六、与第三方共享

不共享。我们不出售、不出租、不以任何形式向第三方提供你的数据，因为本来就没有收集。

Limited Use（有限使用）合规声明：本扩展遵守 Chrome 应用商店的有限使用要求——

  • 不出售用户数据，也不在获批用途之外向第三方转移用户数据；
  • 不将用户数据用于与本扩展单一用途无关的目的；
  • 不将用户数据用于信用评估或借贷相关决策。

本扩展不收集任何用户数据，上述情形均不会发生。

七、你的选择

  • 可以在扩展面板里随时关闭任意功能开关，关闭后对应逻辑不再运行；
  • 可以随时在浏览器扩展管理页停用或卸载扩展；
  • 清除扩展数据即可删除全部本地设置。

八、儿童隐私

本扩展面向《流放之路》玩家，不针对儿童设计，也不会有意收集儿童信息。

九、政策变更

若将来功能变化导致数据处理方式改变，本页面会同步更新并修改顶部生效日期。重大变更会在扩展更新说明中提示。
